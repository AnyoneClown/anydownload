Immich

Send images and direct video files to your Immich library or a writable album.

Up to 500 files per upload · 64 MiB per file

You need an existing Immich server and an API key with asset.upload permission. For a local server, connect to its network or Tailscale.

Connect server

HTTP, HTTPS, local network and Tailscale addresses are supported.

Create an Immich API key

Create a key in your Immich account with asset.upload. For albums, also enable album.read, albumAsset.create and user.read.

API keys are encrypted in your account and never shown again. Media uploads directly from Firefox to Immich.

After connecting

In Media, select files, open the arrow beside Download and choose Upload selected. Pick Library or an album.

Use Uploads to choose local files. Download Telegram or YouTube media first, then upload the saved files.
