Sync data and privacy

Synced preferences include gallery layout, background-image scanning, filters, and filename templates. Ignore rules include site names and hashed media identifiers. Completed-download records include the website, media fingerprint, filename, media type, and completion time.

Your Google account identity and this metadata are stored by AnyDownload on Supabase with per-account access rules. They are not end-to-end encrypted. AnyDownload never stores your Google password or uploads website login cookies.

Files, folders, Save As choices, queues, history, statistics, galleries, trackers, and private-window data stay local to each device.

First sign-in merges local and cloud data. If a preference changes on two devices, the device saving its local edit wins. Local changes sync within seconds; other-device changes are checked about once a minute while Firefox runs. Offline changes remain local until sync resumes.

Pausing stops automatic sync on this device; Sync now still works. Signing out retains local and cloud data, and this installation stays linked to the same Google account. Removing the extension deletes its local copy. Cloud-account deletion is currently managed by the service administrator.
