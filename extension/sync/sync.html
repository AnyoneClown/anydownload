Privacy, storage, and how merging works

Ignore rules include site names and hashed media identifiers. Completed records include the website, media fingerprint, filename, media type, and completion time. Your Google account identity and this metadata are stored on Supabase with per-account access rules; they are not end-to-end encrypted. AnyDownload never stores your Google password or uploads website login cookies.

A local copy remains available offline. First sign-in merges existing local and cloud records. If the same preference changes on two devices, the device saving its local edit wins. Automatic sync checks for other-device changes about once a minute while Firefox is running; browser sleep can delay it.

Pausing stops automatic uploads and downloads on this device; Sync now still works. Signing out stops sync and retains existing data. Removing the extension removes its local copy; cloud-account deletion is currently managed by the service administrator.
